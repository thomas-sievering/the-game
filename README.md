# Games

- [`minigolf/`](minigolf/) – turn-based multiplayer minigolf, live at https://golf.nexus.siever.ing.
- [`lanes/`](lanes/) – 1v1 deckbuilding auto battler (scaffold).
- [`farm/`](farm/) – 1v1 farming race on a shared grid, live at https://farm.nexus.siever.ing.
- [`racer/`](racer/) – top-down arcade racing for up to 8 drivers and bots, three tracks.
